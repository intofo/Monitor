# 架构与覆盖

## 实时监测

`sysinfo` 枚举进程 → Agent 安装/运行线索匹配 → 对开启监测的进程分批采样 → 内存快照 → Tauri / Svelte 界面。

macOS / Linux 使用 `lsof` 获取连接和打开文件线索，Windows 使用 `Get-NetTCPConnection`，尚无对应文件事件传感器。轮询不是完整事件流，会遗漏短连接、快速读取和已经退出的进程。名称、路径及父子关系提供归属线索，不作为系统拦截的可信身份。

macOS 抓包辅助服务以 root 运行，通过当前用户专用 Unix socket 与桌面通信，校验对端身份，只采集选中进程的包元数据，不保存抓包文件。它不提供文件或网络阻断能力。

## 规则与执行器

用户配置存入 `~/.monitor/config.json`，每个 Agent 独立设置。核心引擎负责确定性判定，保存规则不表示执行器已收到或应用规则。

Endpoint Security 原型使用进程 PID/version、UID 和可执行身份建立归属，按根 Agent 的执行实例识别项目，子进程继承该实例范围。Network Extension 原型从 root IPC 获取进程规则快照，通过 audit token 匹配网络流。

可信规则下发、规则版本回执、执行器审计回传与实时 Ask/Jev 审批尚未闭环。进程注册与新连接之间存在时间窗口；未归属流不全局阻断。具体范围见 [拦截进度](protection.md) 和 [原生组件](../native/macos/README.md)。

## 存储与隐私

进程和活动仅保留内存快照。SQLite 保存拦截审计及兼容历史记录；旧代理实现已删除，但旧日志仍可查询。导出仅新建文件，不覆盖已有文件。数据库与配置是本地普通用户数据，不能抵御同用户恶意篡改。

Jev 密钥保存在 macOS 钥匙串；测试仅发送有限事件摘要，不发送源码正文。HTTPS 内部内容不在当前采集能力内，网络白名单不能证明请求不包含代码。

## 离线工具

`monitor-service scan/watch` 对范围限定的历史证据进行只读扫描，`monitor-replay` 处理合成事件回放。两者不生成实际系统阻断，也不是实时文件访问传感器。测试输入中的内容指纹属于调用方声明，不代表已实现内容指纹采集。
