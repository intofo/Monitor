# 验证说明

## 可重复检查

在安装对应平台原生构建依赖后执行：

```sh
cargo fmt --all --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
npm run check
npm run build
```

macOS 扩展另运行两个 `scripts/build_*_extension.py`。构建和可执行文件的 `--check` 只验证本地代码及声明，不证明系统允许加载或拦截成功。

## 自动化测试范围

- 规则判定、目录边界和网络目标匹配。
- 配置持久化、非法更新回滚、历史 SQLite/WAL 迁移。
- Agent 发现、采样轮转、监测开关及活动不落盘。
- 日志分类、导出过滤与禁止覆盖文件。
- 动态项目范围、进程实例隔离、PID 复用和子进程继承。
- 网络规则快照有效期、进程身份和域名/IP/端口约束。
- Jev 请求与响应校验。
- SIP 启用、关闭及未知状态的区分。

旧代理执行器及专属测试已删除，不再把其验证结果作为当前产品能力。

## 尚未完成的验收

- 签名、系统授权、安装、升级、卸载及重启恢复的完整矩阵。
- 关闭 SIP 的开发机真实扩展加载和阻断。
- 桌面规则部署与版本确认、可信审计回传。
- 实时人工 / Jev 审批、超时与恢复行为。
- 原生流归属竞态、现有连接、FD 传递、路径竞态与故障场景。
- 验证目标服务器未收到被禁止的连接或字节。
- Windows / Linux 实机行为与资源占用基准。

CI 编译、单元测试和本地构建均不能代替这些系统级验收。
