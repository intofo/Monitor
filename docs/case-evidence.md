# 离线案例与证据解析

此文档说明保留的解析器和合成测试用途，不代表本项目对任意厂商或当前版本作出行为判定。

## Trae 日志

`monitor-core::evidence` 解析 CKG 阶段的文件数量、上传和失败统计。结果属于应用自报的历史线索，不证明监测器看到了上传正文。当前解析要求阶段标记和统计在同一行，未匹配不表示没有活动。

## ZCode checkpoint

解析 manifest 受理状态、失败次数等字段；pending 文件仅计数，不解密。manifest 状态不推导完整文件包上传成功，失败次数也不能证明历史上从未成功。

## 回放输入

`fixtures/` 中的数据用于确定性规则测试，包含已知端点和未知目标场景。命中端点或输入声明的内容指纹都不是实时传感器证据。规则回放不连接目标、不阻断系统请求，也不写入实际拦截记录。

CLI 用法见 [README](../README.md#命令行工具)。扫描器只读，不修改第三方应用、项目目录或系统网络设置。
